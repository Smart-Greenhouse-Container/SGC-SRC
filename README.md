# IAE.2 SGC

This project aims to develop a smart precision farming system that combines portable modular soil testing laboratories with an AI-powered mobile application to help farmers make better and faster farming decisions. The system works by collecting important soil data such as pH levels, moisture, temperature, nutrient content like nitrogen, phosphorus, and potassium, as well as salinity and organic matter levels through portable soil sensors. This information is then sent to a mobile application where artificial intelligence and machine learning algorithms analyze the data and provide personalized recommendations on irrigation, fertilizer usage, and  uitable crop selection. By giving farmers real-time insights into soil and environmental conditions, the project seeks to improve crop yields, reduce the wastage of water and fertilizers, promote sustainable farming practices, and make modern agricultural technology more affordable and accessible to both small-scale and large-scale farmers.
